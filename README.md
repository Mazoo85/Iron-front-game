# Iron Front

Play: **https://mazoo85.github.io/Iron-front-game/**

World domination from 1939 to today, in the style of World Conqueror 4. This repository holds only
the finished game, published from a private source repository; it is replaced on every update.
On a phone, open the link and choose "Install app" / "Add to Home Screen" to play it like an app,
offline too.
